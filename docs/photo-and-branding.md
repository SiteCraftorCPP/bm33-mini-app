# Фото и брендинг (для заказчика)

## Фото товаров в Google Sheets

- **Одно фото на модель** (Bauer Fuse и т.д.), не на каждый флекс/загиб/L/R.
- **Формат:** горизонтальные предпочтительны **4:3** или **16:9**, ширина от **1200 px**, JPG/WebP.
- **Колонка:** на каждой вкладке добавьте столбец **`Фото`** (сразу после столбца **Цена**).
  - Клюшки, вратарские, коньки, перчатки/защита: колонка **F** (7-й столбец).
  - Термобельё, баулы: колонка **E** (6-й столбец).
- **Ссылка:** вставляйте ссылку на **файл** (не папку), доступ **«все, у кого есть ссылка» → просмотр**.
  - **Google Drive:** `https://drive.google.com/file/d/…/view` — файл должен открываться **без логина** в режиме инкognito.
  - **Яндекс.Диск (как у коньков):** `https://disk.yandex.ru/i/…` — ссылка должна быть **публичной** (кнопка «Поделиться» → «Ссылка»).
  - Если Drive «закрыт», бот **не видит** файл (service account `tgbot-izyatia@tgbot-izyatia.iam.gserviceaccount.com` тоже не поможет, пока владелец не откроет доступ или не даст ссылку Яндекса).
  - **Не** вставляйте общие фото магазина / панорамы — нужен **кадр самой модели** (лучше на светлом фоне, 4:3).
  - Формула `=IMAGE("https://…")` в ячейке тоже поддерживается.
- **Редактирование:** только через таблицу. После правки — **«Обновить из Google Sheets»** (админ): сервер **скачивает фото на диск**; в ответе число «Фото на сервере: N».
- **Сейчас в карточке:** одно изображение. Галерея из нескольких фото — отдельная доработка, если понадобится.

## Как проверить (менеджер / заказчик)

1. **Ссылка в таблице:** скопируйте ячейку **Фото** → вставьте в **режим инкognito**. Должна открыться **картинка**, не логин Google и не страница «войдите».
2. **В магазине:** [ches-hockey.ru/app](https://ches-hockey.ru/app/) → карточка товара → видно фото, не только иконка категории.
3. **Технически (опционально):** в [каталоге API](https://ches-hockey.ru/api/catalog) найдите `"imageUrl": "/api/catalog/image/…"` → откройте `https://ches-hockey.ru` + этот путь — должен быть JPEG, не JSON с `"Image fetch failed"`.
4. **После правки таблицы:** админ → **«Обновить из Google Sheets»** → «Фото на сервере: N». Если `Не удалось скачать M` — файл не в папке бота и не публичный Яндекс (см. ниже).

## Правило «раз и навсегда» для новых товаров

**Один раз настроить доступ (обязательно для Google Drive):**

1. Создайте на Google Drive папку **«Фото Chesalin»** (или любое имя).
2. **Поделиться** → добавить **`tgbot-izyatia@tgbot-izyatia.iam.gserviceaccount.com`** → роль **Читатель**.
3. **Все** фото товаров кладите **только в эту папку** (или в подпапки). В таблицу вставляйте ссылку на файл из этой папки — **не обязательно** «все по ссылке», достаточно доступа для бота.

При каждой синхронизации сервер **сам скачивает** фото и хранит копию у себя (`/var/lib/ches-hockey/catalog-images`). В магазине отдаётся **локальная копия** — Telegram не ходит на Drive/Яндекс при каждом просмотре. Сменили ссылку в таблице → следующий синк обновит файл.

| Ссылка в «Фото» | Что нужно |
|-----------------|-----------|
| Файл из папки, расшаренной боту (см. выше) | Достаточно для Drive |
| `https://disk.yandex.ru/i/…` | Публичная ссылка Яндекса («Поделиться → Ссылка») |
| Drive **вне** папки бота и без «все по ссылке» | **Не скачается** — перенесите файл в «Фото Chesalin» |

**Клюшки:** одно имя на L/R; **Фото** — ссылка из общей папки или Яндекс.

**Коньки:** одна публичная ссылка Яндекса в **Фото** (можно в каждой строке размеров).

## Аватар бота

- Квадрат **512×512 px** (PNG), лицо/логотип по центру — загружается в **BotFather** → Edit Bot → Edit Picture.

## Баннер на главной (hero)

- Файл: `images/baner.jpg` → `web/public/baner.jpg`; для продакшена: `python scripts/optimize_baner_assets.py` (webp + @2x + иконки ярлыка).
- **Размер:** портрет **1920×2560** (файл `images/baner.jpg`). После замены: `python scripts/optimize_baner_assets.py`.
