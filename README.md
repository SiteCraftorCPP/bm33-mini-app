# Ches Hockey Mini App

Локальный MVP Telegram-магазина хоккейной экипировки: каталог из Google Sheets, варианты товаров, фильтры клюшек, корзина, заказ в группу менеджеров, уведомления о поступлении, ссылка на менеджера в Telegram.

## Быстрый запуск на Windows

```powershell
.\scripts\dev.ps1
```

После запуска:

- Mini App: http://127.0.0.1:5173
- API и Swagger: http://127.0.0.1:8000/docs

При первом старте backend читает актуальный публичный каталог Google Sheets. Если таблица недоступна, используется небольшой встроенный demo-каталог.

### Как каталог отслеживает строки

Товары не привязаны к номеру строки. Постоянный идентификатор варианта вычисляется из нормализованных значений:

- категория и название модели;
- флекс/размер;
- загиб/fit/цвет;
- сторона L/R.

Строку можно перемещать, вставлять выше неё другие строки и удалять. Оформление заказа резервирует доступный остаток в приложении, но **не** меняет Google Sheets. Списание в таблицу и в локальной БД происходит, когда менеджер нажимает «Принять» в Telegram: backend проверяет ожидаемый остаток в ячейке и записывает новое значение в текущую строку.

Добавленный вариант или новая модель появляются при следующей синхронизации (по умолчанию не позднее 60 секунд). Удалённый вариант исчезает. Переименование модели или параметра считается удалением старого варианта и созданием нового. Две полностью одинаковые комбинации в одной вкладке запрещены: синхронизация остановится с понятной ошибкой вместо записи не в ту строку.

## Настройка интеграций

1. Скопируйте `.env.example` в `.env`.
2. Укажите `BOT_TOKEN`, `ADMIN_IDS`, группу заказов в `SUPPORT_CHAT_ID` и username менеджера в `MANAGER_TELEGRAM_USERNAME` (без `@`).
3. Для записи остатков создайте service account Google, положите JSON вне Git, задайте `GOOGLE_SERVICE_ACCOUNT_FILE` и дайте email service account права редактора таблицы.
4. На локальной машине оставьте `DEMO_MODE=true`. Перед публикацией установите `DEMO_MODE=false`, `RUN_BOT=true` и HTTPS-адрес в `PUBLIC_WEBAPP_URL`.

Реальные секреты не должны попадать в репозиторий. Токен, ранее сохранённый в локальном файле с доступами, следует перевыпустить через BotFather перед запуском.

## Деплой на VPS (ches-hockey.ru)

Репозиторий: [SiteCraftorCPP/bm33-mini-app](https://github.com/SiteCraftorCPP/bm33-mini-app)

На сервере после клона:

```bash
sudo bash deploy/bootstrap-server.sh
```

Секреты только в `/etc/ches-hockey/env` и JSON service account (не в Git). Шаблон: `deploy/env.production.example`.

Локально (после `git push`):

```powershell
.\.venv\Scripts\pip.exe install paramiko
.\.venv\Scripts\python.exe scripts\deploy_vps.py
```
